md-file-icons
Playground Colors Install GitHub ↗

Material Design · Pure CSS · 0 dependencies

File icons drawn
entirely in CSS.

No SVG sprites. No icon font. One .md-file class, 19 Material colors, 4 sizes, and any label or Font Awesome glyph inside.

Get started Try the playground

Playground

Tune it, then copy the markup.

19 Material colors

Add .md-file-<name>. Click any tile to copy.

Four sizes

.md-file-sm · default · .md-file-lg · .md-file-xl

Put anything inside

A short label, or an <i> from Font Awesome.

Install

npm

npm install md-file-icons
/* CSS */
@import "md-file-icons";

/* or SCSS, to override tokens */
@use "md-file-icons/scss" with ($md-file-background: #222);

CDN

<link
  rel="stylesheet"
  href="https://unpkg.com/md-file-icons/dist/md-file-icons.css"
/>

Markup

<span class="md-file md-file-blue md-file-lg">PDF</span>
